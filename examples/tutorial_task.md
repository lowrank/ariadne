# Tutorial task: AM--GM base case

Give a complete proof that, for every pair of real numbers `a` and `b`,

\[
a^2+b^2 \ge 2ab.
\]

The proof must state the domain and derive the inequality exactly. A numerical
check may be used only as a sanity check, not as the proof. A refutation must
provide an admissible exact counterexample to this precise statement.
